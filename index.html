Lecture 1 يعني إيه Artificial Intelligence؟

Intelligence في أبسط تعريف (Webster) هي the capacity to learn and solve problems، يعني القدرة إنك تتعلم وتحل مشاكل جديدة، وتتصرف بعقل (rationally)، أو تتصرف زي البني آدم. John McCarthy هو اللي سمّى المجال «AI» واخترع لغة LISP، وعرّف الـ AI إنه علم وهندسة صناعة machines ذكية.

Acting Humanly: Turing Test

  • Turing (1950) في ورقة Computing Machinery and Intelligence: سؤال «Can machines think?» هو هو «Can machines behave intelligently?».
  • Imitation Game: بني آدم (interrogator) بيكتب أسئلة وبيستقبل ردود مكتوبة. لو مقدرش يعرف إن اللي بيرد machine، تبقى الـ machine نجحت.
  • Total Turing Test: نفس الاختبار + الجانب الفيزيائي، يعني محتاج كمان Computer Vision وRobotics.
  • ليه نقلّد الإنسان أصلًا؟ لأن الإنسان لسه هو الـ Gold Standard في مهام كتير.
  • BabyX: طفل افتراضي بيتعلم بالـ Reinforcement Learning (مكافأة وعقاب) وبيستخدم Affective Computing (يفهم ويحاكي المشاعر).

Chinese Room و Strong vs Weak AI

  • John Searle: واحد في أوضة معاه كتاب تعليمات، بيستقبل رموز صيني ويطلّع ردود صح من غير ما يفهم ولا كلمة. نفس الكلام على الـ computer: بينفّذ program بس.
  • من غير understanding (intentionality) مفيش thinking ولا mind، وبالتالي Strong AI is false.
  • Weak AI: نقدر نحاكي (simulate) ذكاء الإنسان. Strong AI: نقدر نعمل ذكاء حقيقي فيه consciousness وself-awareness وfree-will.
  • ANI = task واحدة بشكل ممتاز (إحنا هنا دلوقتي) ← AGI = يفكر زي العقل البشري ← ASI = أذكى من البشر.

Thinking Humanly و Thinking Rationally

  • Thinking Humanly: نفهم المخ كـ information processing machine، ونكتب نظرية للعقل كـ program ونقارنها بسلوك الإنسان. مرتبطة بالـ Cognitive Science والـ Neuroscience، واسمها كمان descriptive approaches.
  • Thinking Rationally: الـ Logic، يعني استنتاج صحيح دايمًا (Socrates is a man…). أمثلته: Propositional Logic (AND / OR / NOT)، وLogic Programming (Prolog: facts + rules + queries)، وSemantic Networks (graph: concepts = nodes، relations = edges).
  • مشاكلها: صعب نكتب العالم الحقيقي بالـ logic، والـ uncertainty، والـ computational complexity، وإن «rational behaviour» كتير مالوش علاقة بالـ logic.

Acting Rationally: Intelligent Agents

  • ليه؟ لأن لازم نتصرف حتى لو مفيش حاجة صح مثبتة (reasoning under uncertainty)، وكمان فيه سلوك reactive (instinct).
  • الـ intelligent agent (Poole & Mackworth): أفعاله مناسبة لأهدافه، flexible، بيتعلم من الخبرة، وبياخد أحسن قرار في حدود قدراته (bounded rationality).
  • بنسيب شرط cognitive plausibility، يعني مش لازم نفكر زي الإنسان. زي الطيارة اللي اتعملت بالـ aerodynamics مش بتقليد الطير.
  • Robots = agents ليها وجود فيزيائي. Interface agents = software (recommender systems، tutoring systems)، وهي اللي بنركّز عليها في الكورس.

Lecture 2 Intelligent Agents & Environments

Agent = أي حاجة بتحس بالبيئة عن طريق Sensors، وبتأثر فيها عن طريق Actuators. والدورة: Sense ← Reason ← Act ← Get Feedback ← Learn.

Vacuum agent: الـ percept = [location, status] زي [A, Dirty]، والـ actions = Left / Right / Suck / NoOp. لو Dirty يبقى Suck، ولو في A يروح Right، ولو في B يروح Left. عدد الـ states = n·2ⁿ (لو مكانين يبقوا 8).

Rational agent: بيختار الـ action اللي متوقع يعمل maximize للـ performance measure (اسمه كمان utility function، وهو objective criterion for success).

False Positive و False Negative

  • FP (Type I error): قلت «أيوه» والحقيقة «لأ»، زي «You’re pregnant» لراجل، أو إيميل مهم راح spam.
  • FN (Type II error): قلت «لأ» والحقيقة «أيوه»، زي «You’re not pregnant» لست حامل، أو مرض اتفوّت.

Goal-based vs Cost-based

  • Goal-based: الـ actions بتعتمد على الهدف، زي روبوت رايح أوضة 179.
  • Cost-based: بيقلّل تكلفة القرارات الغلط على المدى الطويل، وكل نوع error ليه وزن. مثال الـ spam: Agent 1 غلط 12 مرة بس ضيّع 11 إيميل مهم، فهو أسوأ من Agent 2 اللي غلط 38 مرة كلها spam دخل الـ inbox.

Environment Types

  • Fully vs Partially Observable: الـ sensors شايفة الحالة كلها ولا لأ؟
  • Deterministic vs Stochastic (vs Strategic): الحالة الجاية متحددة ولا فيها عشوائية؟ والـ Strategic = deterministic ما عدا حركات الخصم.
  • Episodic vs Sequential: قرارات منفصلة ولا كل قرار بيأثر على اللي بعده؟
  • Static vs Dynamic (vs Semi-dynamic): العالم بيتغير وانت بتفكر؟ والـ Semi-dynamic = البيئة ثابتة بس الـ score بيتأثر بالوقت (زي الشطرنج بالساعة).
  • Discrete vs Continuous، وSingle vs Multi-agent.
  • Known vs Unknown: عارف قوانين البيئة ولا لأ. دي صفة في معرفة الـ agent، مش في البيئة.

Lecture 2 ML, Data Mining & Big Data

  • Learning agent: بيغيّر نفسه من الـ training examples أو الـ feedback، عشان الـ average utility بتاعته تزيد مع الوقت.
  • AI ⊃ ML ⊃ DL: الـ Deep Learning جزء من الـ ML، والـ ML جزء من الـ AI. والـ DL = hierarchy of layers بتطلّع features أكثر abstraction.
  • ML vs Data Mining: الـ ML بيعمل prediction من known properties، والـ DM بيعمل discovery لـ unknown properties، والـ DM هو الـ analysis step في KDD.
  • Data Science = statistics + data processing + ML + visualization + business analytics + big data… وأمثلة الـ empirical (من الداتا مش من النظرية): الفرتيليزر (experimental data)، والـ Streptomycin (randomized trials)، والتدخين (observational studies)، والـ Moneyball (Oakland A’s 2001).

Lecture 3 Problem Solving as Search

  • Reflex agent: بيبص على الدنيا «IS»، وبيقرر من الـ percept الحالي ومش بيفكر في العواقب. Planning agent: بيبص على الدنيا «WOULD BE»، وبيفكر في العواقب، ومحتاج model وgoal.
  • البني آدم مش بيعمل exhaustive search، بيستخدم heuristics (judgmental rules من الخبرة). الـ heuristic بيوجّه البحث للطرق الأقرب للنجاح، بس مش بيضمن الحل الأمثل.
  • Search problem: Initial state + Actions + Transition model + Goal state + Path cost (مجموع step costs موجبة). والـ optimal solution = أقل path cost.
  • State space: كل الـ states اللي ممكن نوصلها، وبتتمثل كـ graph: الـ nodes = states، والـ arcs = actions. وبتتكتب [N, A, S, GD] = Nodes, Arcs, Start, Goal.

  • Data-driven (forward chaining): بنبدأ من الداتا. بنستخدمه لما الداتا موجودة، والـ goals كتير أو صعب نحددها، وطرق استخدام الـ facts قليلة.
  • Goal-driven (backward chaining): بنبدأ من الـ goal. بنستخدمه لما الـ goal معروف، والـ rules كتير، والداتا مش موجودة. مثال: theorem prover.
  • Node ≠ State: الـ state = شكل العالم، والـ node = data structure فيه state + pointer للـ parent + path cost.
  • Tree search: بنحط الـ start في الـ frontier، وبعدها في كل خطوة نختار node، لو goal نرجّع الحل، ولو لأ نعمل expand ونضيف أولادها.
  • Repeated states: بنحفظ explored set ومش بنرجّع حاجة اتشافت. وفي 8-queens مفيش تكرار، والـ assembly planning فيه تكرار قليل، والـ 8-puzzle وrobot navigation فيهم تكرار كتير.

Lecture 5 Blind (Uninformed) Search

Blind = Uninformed = Exhaustive = Brute-force: مش بيستخدم أي معلومة عن الـ state. Heuristic = Informed: بيستخدم المعلومات عشان يعرف أنهي node «more promising».

Lecture 5 Heuristic (Informed) Search

  • g(N) = التكلفة الفعلية من الـ start لـ N (والـ start نفسها g = 0). h(N) = تقدير التكلفة من N للـ goal. f(N) = evaluation function.
  • f = h يبقى Greedy best-first، وf = g + h يبقى تكلفة الحل كله لو عدّينا من N (فكرة A*).
  • Best-First: فيه open list (priority queue مترتبة بالـ heuristic) وclosed list، والأفضل بيتبحث الأول حتى لو من أي level.
  • 8-puzzle heuristics: misplaced tiles، وsum of distances (Manhattan)، و2 × عدد الـ direct tile reversals.
  • Robot navigation: الـ h = straight-line distance √((Xg−XN)² + (Yg−YN)²).
  • Symmetry reduction: أول حركة في Tic-Tac-Toe بتبقى 3 بس (corner / edge / center) بدل 9. Heuristic reduction (most winning lines): الـ center = 4، والـ corner = 3، والـ edge = 2.
  • Hill Climbing: بيختار أحسن child بس، ومش بيحتفظ بالبدائل، فممكن يقف عند local maximum. ونفس الكلام في الـ Steepest descent: ممكن يقف عند local minimum.
  • كل ما الـ heuristic function كانت أدق، البحث بقى أسرع.

Lecture 6 Adversarial Search (Games)

  • لعبة فيها لاعبين بنفس المعرفة، والصعوبة الأساسية إننا نحسب حساب حركات الخصم.
  • Minimax: بنعلّم كل level بـ MAX أو MIN. الـ MAX بياخد أكبر قيمة في أولاده، والـ MIN بياخد أصغر قيمة، ونطلع من تحت لفوق. في الـ Nim الأوراق قيمتها 0 أو 1 (win لـ MIN أو لـ MAX). ولو الشجرة كبيرة بنقف عند fixed ply depth وبنستخدم heuristic evaluation.
  • Alpha-Beta pruning: بيقلّل عدد الـ nodes اللي بنقيّمها، وبيرجّع نفس الحركة اللي Minimax بيرجّعها. بيستكشف depth-first.
  • α = أحسن اختيار لـ MAX، وعمرها ما بتقل. β = أحسن اختيار لـ MIN، وعمرها ما بتزيد. الـ prune بيحصل لما α ≥ β.
  • تقنيات تانية: Evolutionary (Genetic) Algorithms، وSwarm Intelligence، وSimulated Annealing.
  • نستخدم الـ search إمتى؟ لو الـ search space صغير، أو كبير بس عندنا heuristics كويسة.

أهم النقط

  1. الأربع approaches: Thinking/Acting × Humanly/Rationally، وكل واحدة ليها اسم وأصحاب تعريفات.
  2. الـ Turing Test = Acting Humanly، والـ Total Turing Test بيضيف Computer Vision وRobotics.
  3. الـ Chinese Room بيقول إن Strong AI غلط، لأن مفيش understanding.
  4. Weak AI = simulate، وStrong AI = mind حقيقي. وANI ← AGI ← ASI.
  5. Agent = Sensors + Actuators، والـ rational agent بيعمل maximize للـ performance measure.
  6. PEAS: اعرف تفرّق بين P وE وA وS في أي مثال.
  7. FP = إنذار كاذب (Type I)، وFN = حاجة فاتتنا (Type II).
  8. Goal-based = عايز يوصل لهدف، وCost-based = الأخطاء ليها تكلفة.
  9. جدول الـ environments: Semi-dynamic = Chess with clock، وStrategic = deterministic + خصم.
  10. AI ⊃ ML ⊃ DL. والـ ML بيعمل prediction، والـ DM بيعمل discovery (KDD).
  11. Classification = category، وRegression = رقم، وClustering = مجموعات من غير labels، وRL = rewards.
  12. الـ 5 Vs: Volume, Velocity, Variety, Veracity, Value.
  13. Reflex = IS، وPlanning = WOULD BE. والـ heuristic مش بيضمن الحل الأمثل.
  14. DFS = Stack، وBFS = Queue، وUCS وBest-First = Priority Queue، وBidirectional = Queue.
  15. BFS وIDS بيضمنوا أقصر حل، وIDS عنده space قليل زي DFS.
  16. g = من الـ start لـ N، وh = من N للـ goal، وf = g + h.
  17. Hill climbing ممكن يقف عند local maximum.
  18. Minimax للألعاب الثنائية، وAlpha-Beta = نفس النتيجة بـ nodes أقل.

هنتات الامتحان

  • «simulate / mimic human» يبقى Acting Humanly. «optimal / best move / agent» يبقى Acting Rationally. «reasoning / logic» يبقى Thinking Rationally.
  • سؤال Total Turing Test غالبًا إجابته All of the above.
  • في سؤال «can NOT be described as»، دوّر على الصفة الوحيدة اللي بتعارض الجدول. للـ Driving والـ Chess with clock الإجابة كانت Static.
  • أي لغز لاعب واحد (N-Queens، Sudoku) مش adversarial ومش Strategic، والإجابة غالبًا Static أو Discrete.
  • جمل الـ True/False بتتعكس بين النماذج (ML ↔ DM، Classification ↔ Regression، arc ↔ vertex)، فاقرا الجملة كلها كويس.
  • «y real-valued» يبقى Regression، و«y categorical» يبقى Classification.
  • «flagging legit / unauthorized access» يبقى قلّل FP. «missing illness» يبقى قلّل FN.
  • «placing a stone / queen / brushes» يبقى Actuators. والـ «Quality, price…» يبقى P.
  • g(N) للـ puzzle اللي اليوزر إداه = 0. وفي N-Queens الـ g غالبًا = عدد الوزرا اللي اتحطوا.
  • Board = node، وmove = arc. وN-Queens مفيش فيها repeated nodes.
  • TSP = (n − 1)!، وTic-Tac-Toe = 9!، و8-puzzle = 181,440.
  • سؤال Fringe: Best-First + UCS = Priority queue للاتنين، وBFS + Bidirectional = Queue للاتنين.
  • Backtracking ≈ DFS في الترتيب، فـ ([A], [B A], [D B A]) تبقى SL + DFS closed (a & b).
  • Sudoku «stuck in local optimum» يبقى Hill Climbing.
  • Alpha-Beta: امشي left to right (أو right to left لو السؤال قال كده). أول ما الـ MIN يبقى ≤ α اقطع الباقي، وأول ما الـ MAX يبقى ≥ β اقطع الباقي.
  • Brute-force في الشطرنج: الوقت بيعتمد على عدد الحركات في كل دور (branching factor). والأنسب للشطرنج Alpha-Beta. والـ Bidirectional في الشطرنج False.
